あなたのデバイスが手元を離れるとき——修理店、第三者への引き渡し、共有デスク、あるいは従業員・業者・内部関係者の管理下——Black Box は、そこで何が起きたかを **改ざん検知可能（tamper-evident）でハッシュ連鎖された記録** として残します。開かれたすべてのファイル、接続されたすべての USB デバイス、ログイン、実行されたプロセス。Windows 10 および 11 向けの、フォレンジック水準の活動ログです。

## ガジェットではなく、本来すでに存在すべきカテゴリ

Black Box は「修理店向けのツール」と誤解されがちですが、そうではありません。修理店は、デバイスがあなたの管理を離れる分かりやすい一例にすぎず、その発想ははるかに広いものです。

航空機にはブラックボックスがあります。列車、船舶、電力網、さらには病院にもあります。高リスクのあらゆる分野が同じ教訓を学びました。何かが起きたとき、記憶にも、信頼にも、「その場に誰がいたか」にも頼れない——出来事のあとも残り、ひそかに書き換えられない記録が必要だ、と。あなたのお金、仕事、私生活を動かす唯一のデバイスだけが、それを持ちませんでした。

## Black Box とは

多くのセキュリティツールは、ネットワーク経由の攻撃を止めるために作られています。Black Box は、どのツールもカバーしない瞬間のために作られました。デバイスが物理的に他人の手にあり、リスクがプログラムではなく「人」であるときのためです。

それはあなた自身のマシン上で目に見える形で動作し、活動を記録します——ファイルアクセス、プロセス実行、USB デバイスの接続、ログイン、重要な変更を、**SHA-256 のハッシュ連鎖**へと。各エントリは直前のハッシュで封印されるため、いずれかを編集・削除すると連鎖が目に見えて壊れます。ログはあなたの PIN から導出された鍵でデバイス上に暗号化され、Alcyone でさえ読むことはできません。

- **個人には永久に無料。** ローカル記録、USB ブロック、フォレンジックレポートを無償で。
- **ローカルファースト。** 任意の暗号化クラウドバックアップを有効にしない限り、何もデバイスの外へ出ません。
- **Windows 10 と 11。** 小さなインストーラー（4.41 MB）、完全にオフラインで動作します。

## 誰のためのものか

- **個人** — デバイスを修理店や友人、目の届かない相手に預ける人。
- **企業** — *このマシンで誰が何をしたのか、そして証明できるのか* に答える必要がある組織。内部リスク、業者アクセス、機器の引き渡し、DPDP／GDPR 水準の説明責任のために。
- **世界中のすべての人。** Alcyone Secure は **グローバルを志向するインドの企業** です。他人の手に渡ったデバイスは、普遍的な問題です。
