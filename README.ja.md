# Alcyone Secure の Rashnova：公開ドキュメント

> **言語** · [English](README.md) · [हिन्दी](README.hi.md) · [മലയാളം](README.ml.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · **日本語** · [Bahasa Indonesia](README.id.md)

**Rashnova は Windows のための「証拠のレイヤー」です。** 人やプログラムがあなたの PC で何をしたかを、
封印された改ざん検知可能な記録として残す無料のアプリです。誰かに PC を預けていた間に何があったのかを、
後から確かめられます。修理店でも、社内の IT 窓口でも、家族で使うパソコンでも、友人に貸したときでも、
Rashnova は差し込まれた USB メモリ、開かれたファイルとコピーされたファイル、起動されたプログラム、
サインインを記録し、各エントリをひとつ前のエントリと封印でつなぐため、どんな変更も表に出ます。
[Alcyone Secure](https://www.alcyonesecure.com) が Windows 10 / 11 向けに開発しています。

> セキュリティは防御だけではない。セキュリティとは説明責任である。
> **信頼は良い。証拠はもっと良い。**

*Rashnova は 2026 年まで **Black Box** という名前でした。同じレコーダー、同じチーム、新しい名前です。*

## Rashnova にできること

- **The Readout.** 週に一度、あなたのマシンが何をしたかについての明確な判定と、確認すべき項目を最大
  3 つ表示します。各項目にあなたが答えます：*自分だった*、または*自分ではない*。
- **Repair Mode.** 修理店や IT サポート、その他の誰かにノートパソコンを渡す前に、見守りセッションを
  開始します。戻ってきたら判定付きのレポートが届きます。何が開かれ、コピーされ、名前を変更され、
  削除されたか、どのプログラムが動き、どの USB デバイスが接続されたか（コピーされたファイルを含む）。
  セッションを終了できるのはあなたの PIN だけです。
- **Handover Mode** *（1.2 の新機能）*. 家族や友人、同僚にパソコンを貸すときの、同じ見守りセッション。
- **USB ストレージのブロック** *（1.2 の新機能）*. 設定にある、PIN で保護されたスイッチです。USB
  メモリや外付けディスクが開かなくなります。Rashnova を通さずに USB ストレージを再び有効にすると
  改ざんとして記録され、数秒以内に再びブロックされます。
- **常時記録（選んだ場合のみ）.** あなたがオンにするまではオフで、ワンクリックでオフに戻せます。
  記録するのは取り返しのつかないことと警戒すべきこと（完全な削除、機密に見えるファイル、リムーバブル
  ドライブへ移るもの）で、自分のファイルを日常的に使うことではありません。
- **検証できる記録.** 各エントリはひとつ前のエントリと封印でつながっているため、記録の改変や欠落は
  表に出ます。セッション中の再起動やスリープは時間とともに表示され、Windows が動いている間に
  レコーダーが停止された場合は改ざんとして記録されます。
- **Monitor Now.** 何かおかしいと感じたときに、30 秒間のファイル操作をリアルタイムで確認できます。
- **レポート** は PDF、ウェブページ、スプレッドシートで出力でき、誰にでも渡せます。

**決して記録しないもの：** 画面、キー入力、パスワード、メッセージの内容、ファイルの中身、ウェブカメラ。
記録するのは「何かが起きた」という事実で、あなたが何を見ていたかではありません。

## ガジェットではなく、本来あるべきカテゴリー

航空機にはフライトレコーダーがあります。列車、船舶、電力網、病院にも記録の仕組みがあります。リスクの
高い分野はどこも同じ教訓を得てきました。何かが起きたとき、記憶にも、信頼にも、その場にいた人にも
頼れない。出来事を越えて残り、黙って書き換えられない記録が必要だ、と。あなたのお金、仕事、私生活を
動かしているデバイスだけが、それを持っていませんでした。考え方は
**[コンピューターにフライトレコーダーが必要な理由](docs/why-a-black-box.md)**、創業者の話は
**[Rashnova が生まれた理由](docs/why-it-exists.md)** をご覧ください（英語）。

**EDR ですか？** いいえ。EDR と競合するものでもありません。ウイルス対策ソフトや EDR は悪意のある
コードを監視します。Rashnova が見張るのはもう一つの扉、つまり正当なアクセス権を持つ*人*がマシンを
手にしたあとに何をするかです。EDR を使っているなら、Rashnova は EDR が本来担えない説明責任の
レイヤーになります。企業向けツールが手の届かない価格なら、Rashnova は無料の第一歩です。

**スパイウェアですか？** いいえ。デバイスの所有者のために作られ、隠れずに動作し、記録はそのデバイスに
保存されます。利用規約は、法的根拠なく誰かを監視する目的での使用を禁じています。共有のパソコンで
使う場合は、使う人たちに伝えてください。

## 対象となる人

- 修理店や友人、目の届かない誰かにノートパソコンを預ける**個人**。
- 1 台のパソコンを共有し、誰も責めずに何があったかを知りたい**家族**。
- 論文やクライアントのファイルが 1 台のマシンにある**学生やフリーランス**。
- *このマシンで誰が何をしたか、それを証明できるか*に答える必要がある**組織**：端末の引き渡し、業者の
  訪問、内部リスク、インドの DPDP 法（2023 年）、GDPR、CCPA に向けた証拠。

Alcyone Secure は**世界を視野に入れたインドの企業**です。他人の手にあるデバイスは、どこにでもある
問題です。
